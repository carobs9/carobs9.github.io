I keep learning about Git every day at work and making several mistakes. I have decided to write a cheatseet where I can revisit my old mistakes and not make them again. I hope I can help others. 

I was inspired by [Oh Shit, Git!?!](https://ohshitgit.com/) and the [w3schools git tutorial](https://www.w3schools.com/git/git_branch_merge.asp?remote=github). However, I wanted to tailor the cheatsheet towards my typical mistakes and my workflow. I also tend to learn faster when I type things down myself.

It seems like I keep making a lot of Git-related mistakes so the cheatsheet is being updated regularly at a fast pace. You can access the cheatsheet (in continuous improvement) here: [git-notes](https://github.com/carobs9/data-science-notes/blob/main/git-notes.md)
